# CineVault — TMDB Movie Explorer

Responsive movie/TV discovery site built with HTML, CSS and JavaScript.

## Features
- Trending movies and TV shows
- TMDB search
- Movie/TV detail modal
- Ratings, year, genres and overview
- Mobile-first dark UI
- Browser-only TMDB key storage
- GitHub Pages deployment workflow

## Setup
Open the site, press **⚙ Settings**, paste your TMDB API key, and save it. The key is stored in this browser's local storage and is not committed to the repository.

## GitHub Pages
The repository includes `.github/workflows/pages.yml`. Enable **Settings → Pages → Source → GitHub Actions** if Pages is not already enabled. GitHub Pages supports publishing static HTML/CSS/JS from a repository.

## Video playback
The project does not include third-party copyrighted streaming sources. Add only video URLs or embeds that you own or are authorized to distribute.
